claudegmail

A personal tool that lets Claude read and manage several Gmail accounts from one place.

claudegmail is a small program that runs on its owner's own computer. It connects Claude (Claude Desktop and Claude Code) to more than one Gmail account at a time, so the owner can search, read, draft, send and organize mail across accounts without switching between them.

Who it's for

It's a private, single-user tool. It isn't a hosted service, and there's no sign-up. Only the owner's own Google accounts are connected.

How it works

  • The owner signs in to each Gmail account once with Google's standard sign-in.
  • The sign-in tokens are stored only on the owner's computer.
  • Claude asks the program to look up or change mail, and the program calls the Gmail API directly from that computer.
